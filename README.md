## D&D Character Manager
## Класи
**CharacterClass** — містить доступні класи персонажів: *Warrior*, *Mage*, *Rogue*.
**DndCharacter** — основний клас персонажа. У ньому є ім'я, клас персонажа, рівень, здоров'я, фракція та досвід. Також є методи для додавання досвіду та отримання урону.
**CharacterManager** — дозволяє додавати персонажів, показувати список, шукати персонажа, видаляти персонажа та демонструвати його дії.

## Program. 
У *Program* знаходиться головне меню програми. Користувач вибирає потрібну дію через цифри. У програмі є перевірка введених даних. Якщо користувач вводить неправильне значення, програма показує помилку та просить ввести дані ще раз.

## ООП
У програмі використовуються:
* класи
* об'єкти
* приватні поля
* властивості
* конструктори
* методи
* *enum*
* *List*
* інкапсуляція
* обробка помилок через *try-catch*

## Запуск
Відкрити проєкт у Visual Studio.
Відкрити файл проєкту.
Запустити програму в терміналі:
*dotnet run*
Після запуску з'явиться меню програми.
